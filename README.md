# Agenda SP
1. Crie um repositório no GitHub e suba estes arquivos.
2. Settings > Pages > Deploy from branch (main). Ou conecte o repo ao Netlify/Cloudflare Pages.
3. Em sources.json, adicione páginas de agenda que tenham dados schema.org/Event (use enabled: true).
4. Troque o contato em UA no scripts/collect.py. O workflow roda 2x por dia e atualiza events.json.
Antes de ativar uma fonte, confira os termos de uso e o robots.txt dela.
